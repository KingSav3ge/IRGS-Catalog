# Alpha candidate contexts and communication selection 1

This independent offline evaluation selects the explicitly fictional 1415 quay
opening and fictional R00 settlement as **provisional candidates** in distinct
campaign families. Both use normal reviewed creation. Neither is Alpha-qualified:
the evaluator-only matrix records bounded existing behavior and missing participant,
needs, NPC/institution and consequential conflict requirements. A dated source
does not establish historical personal facts, and the named R00 neighbors do not
create automatic NPC decisions. The matrix is an assessment, not a new ruleset.

(SHA-256 `eb182aef5f15ad199e8a54a8d9a7c6890b78ae26631c0125d04f6bb58dc43f34`).
