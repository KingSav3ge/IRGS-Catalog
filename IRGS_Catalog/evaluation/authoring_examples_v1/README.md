# Original world-authoring reference examples v1

These are original fictional Catalog-authored content requirements for two
families: an independent quay and an R00-style settlement. They are data-only
reference examples, not Engine world-draft DTOs, initializers, imported world
packs, playtests or playable campaigns. The World Builder plan describes required
areas, but Engine has not published a world-draft/package DTO at selected Engine
`296e46a1beed10d0ebf2841f133bb52fade83697`. Do not treat these fields as its
API; map them only after the owner publishes the actual contract.

Each authored example separates actor instructions from evaluator-only checks,
identifies a controlled actor and separate contact, two linked places and one
finite proposed item, gives source/provenance and selected initial knowledge,
and distinguishes unknown units/rules, actual custody and initialization. Draft
labels and a proposed item do not create stock, authority, travel times or facts.
No third-party code, image, historical record, credentials or campaign save is
included. Original source assertions are fictional and may be used offline.

`world_authoring_examples.validate` checks this Catalog fixture's bounded
references, source status, separation and unresolved owner dependencies. It is
not Engine's validator; import/export, object-level rules, review/creation,
privacy and real playtests remain unexecuted. No world-builder feature or Alpha
gate is claimed complete.
